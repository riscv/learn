## ➕ Making Contributions

Anyone can contribute, and no special access is needed. First check the [README](README.md#find-resources) to see whether your resource is already listed.

### Open a pull request (fastest)

1. Edit `README.md` and add one row to the table that fits: Beginner, Intermediate, Specifications and Reference, Software and Tools, Software Ecosystem and Porting, Open RISC-V Implementations, Verification and Compliance, Boards, Articles and Presentations, or Community.
2. Keep the table in alphabetical order, and put today's date (YYYY-MM-DD) in **Date Added**.
3. Write a one-line description of what a learner gets from it. Open implementations need an open-source licence.
4. Sign off your commit (`git commit -s`). The DCO check is required on every pull request.

### Or open an issue

Use the **Addition of new RISC-V tutorial resource** template under [New issue](https://github.com/riscv/learn/issues/new/choose), and we'll add it for you. For anything else, use **General Request**.

We may ask for more details before adding a contribution.
