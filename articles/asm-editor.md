# ASM Editor: un parcours interactif pour apprendre RISC-V

ASM Editor est un environnement web interactif pour écrire, exécuter et déboguer des programmes RISC-V en RV32 et RV64.

**Accès direct :** https://asm-editor.specy.app/

## Ce que l'outil permet

- écrire du code assembleur avec complétion automatique ;
- avancer instruction par instruction et observer les registres ;
- suivre la pile et la mémoire pendant l'exécution ;
- consulter la documentation intégrée des instructions RISC-V ;
- comparer les comportements RV32 et RV64.

## Parcours pédagogique reproductible

#1. Commencer par un programme qui charge deux valeurs et observe les registres.
#2. Ajouter une boucle et utiliser le pas-à-pas pour relier le code à l'état du processeur.
#3. Inspecter la pile après un appel de fonction.
#4. Reprendre le même exemple en RV64 et noter les différences de largeur.
